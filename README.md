# Asterisk Telephony Analytics

## Описание проекта
Проект представляет собой систему аналитики телефонии на базе Asterisk CDR, MySQL, Python и Google BigQuery.

Основная цель проекта - автоматизировать сбор, хранение, обработку и анализ данных звонков для мониторинга KPI телефонии и эффективности менеджеров.

---

# Архитектура проекта

Asterisk MySQL → Python ETL → BigQuery → SQL Transformations → Dashboard

---

# Реализованный функционал

## Сбор данных
Реализовано подключение к MySQL-базе Asterisk CDR для получения:
- истории звонков,
- длительности разговоров,
- статусов звонков,
- информации о маршрутизации вызовов.

Для обеспечения безопасности доступ к базе данных был организован через whitelist статического IP-адреса клиента.

---

## ETL-процессы
Разработаны ETL-скрипты на Python для:
- извлечения данных из MySQL,
- incremental loading,
- historical loading,
- загрузки данных в BigQuery,
- дедупликации данных,
- обновления существующих записей через MERGE.

---

## SQL и аналитика
Созданы SQL-витрины и аналитические представления для:
- расчета KPI,
- анализа эффективности менеджеров,
- анализа успешности звонков,
- агрегаций по времени,
- dashboard-отчетности.

# Метрики dashboard
В dashboard реализованы:
- количество попыток звонков,
- количество дозвонов,
- количество успешных звонков,
- доля успешных звонков,
- средняя длительность разговора,
- время ожидания,
- время диалога,
- эффективность менеджеров,
- распределение звонков по времени,
- динамика звонков по периодам.
